# Teaboom, карточка товара

Тестовое задание: верхняя часть карточки товара для teaboom.ru,
за основу взял [Ананасовый улун](https://teaboom.ru/product/ananasovij-ulun).

Посмотреть можно тут: https://leden4ik.github.io/teaboom-product-card/

Собирается моим обычным сборщиком на Gulp: Pug, SCSS, esbuild.
Фреймворков нет, js простой, на DOM API.

## Как запустить

Нужен Node 18+ (я сидел на 20, версия в `.nvmrc`).

```bash
npm install
npm run dev      # локальный сервер на http://localhost:3000
npm run build    # сборка в dist/
npm run zip      # архив из dist/
npm run deploy   # заливает dist/ на gh-pages
```

Готовая страница собирается в `dist/index.html`. Открывать лучше через `npm run dev`,
а не просто файлом: иконки лежат в svg-спрайте, и с `file://` браузер их не подтянет.

## Что по функционалу

При смене фасовки меняются цена, старая цена, артикул и выбранная плашка.
Заодно пересчитываются выгода, скидка на фото и цена за 100 г. Последнюю добавил,
потому что скидки у фасовок сильно разные, и так сразу видно, что 5 кг выходят
в два с лишним раза дешевле за грамм, чем 100 г.

Фасовки сделал обычными radio внутри fieldset, чтобы работали с клавиатуры
и нормально читались скринридером. Выбранную подсвечивает css через `:has(:checked)`,
js только меняет цифры.

Кнопка «В корзину» как на сайте: жёлтая, при наведении становится тёмной с жёлтым
текстом. Корзины нет, поэтому по клику она просто на пару секунд показывает «Добавлено».
Сердечко «в избранное» тоже переключается.

Цены вывожу через `Intl.NumberFormat`, копейки только если они есть:
326,40 ₽, но 1 432 ₽.

## Адаптив

Смотрел на 1440, 768 и 375.

- на десктопе фото слева и не уезжает при прокрутке, всё остальное справа
- на планшете фото и покупка в две колонки, описание ниже на всю ширину
- на мобилке всё в одну колонку, название над фото, хлебные крошки
  сворачиваются до ссылки на родительскую категорию

Сетка фасовок (4 в ряд или 2 на 2) зависит от ширины колонки, а не экрана,
сделал на container queries.

## Про стиль

Цвета и шрифт снял с teaboom.ru: Open Sans, жёлтый `#f5d730`, тёмный `#202020`,
текст `#444`. Фото, логотип и тексты тоже оттуда. Редизайн не делал, только чуть
освежил подачу: скругления, побольше воздуха, фасовки плашками вместо списка.

В Open Sans нет знака ₽, он берётся из системного шрифта, на глаз разницы нет.

## Где что лежит

Править всё в `src/`, `dist/` пересобирается каждый раз.

```
src/
  tmp/                          pug-шаблоны
    index.pug                     страница
    module/product/product.pug    карточка
    _config/product-data.pug      данные: фасовки, цены, тексты
  scss/
    config/                       переменные, миксины, брейкпоинты
    module/product/product.scss   стили карточки
  js/modules/product.js         фасовки, корзина, избранное
  icons/                        svg для спрайта
  img/                          фото и логотип, webp и avif делаются при сборке
  fonts/                        Open Sans, обрезанный до кириллицы и латиницы
```

Классы с префиксом `tb__`, чтобы не пересекаться со стилями сайта, если
вставлять блок туда. Хуки для js начинаются с `js--`, стили на них не вешаю.
Размеры пишу в px, при сборке они переводятся в rem.
